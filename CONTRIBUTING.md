# Contributing to Eclipse Animator — Free Release

This repository is an archive of the last free build. No new plugin features are planned here, but bug reports and documentation improvements are welcome.

## Bug Reports

Open an issue using the Bug Report template. Include:

1. Roblox Studio version (Help / About).
2. Operating system and version (Windows 10/11, macOS version, or Linux distro + Wine / Vinegar version).
3. Release tag and file name you installed (for example `v1.0957-free / Eclipse-Animator-inspect.rbxmx`).
4. Rig type (R6, R15, custom, Blender-imported).
5. Exact steps to reproduce.
6. Expected behavior and actual behavior.
7. Screenshots or video if the issue is visual.

## Documentation

Documentation fixes are the fastest way to help:

- Fix a wrong step in `README.md`.
- Clarify Windows, macOS, or Linux install paths.
- Improve troubleshooting entries.
- Fix typos or broken links.

Open a pull request against `main`. Keep changes small and focused. Do not add emojis to the README.

## Feature Requests

Use the Feature Request template. Note that this archive is frozen at the free build, so requests are tracked for documentation and community workarounds, not for new plugin development.

## What Not To Do

- Do not repackage and resell this build.
- Do not open pull requests that replace the `.rbxmx` with an unverified rebuild.
- Do not commit Studio autosaves, place files, or personal animation data.

## Code of Conduct

Be respectful. No spam, no harassment, no misleading download links. Keep discussions focused on animation and Studio workflow.
